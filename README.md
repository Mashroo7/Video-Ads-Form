# Video Ads — customer request form

Public form for the TikTok/Instagram bio link. Hosted with GitHub Pages: `https://<owner>.github.io/video-ads-form/`.

- `index.html`: the form. Arabic, mobile-first, 5 tap-to-answer steps, with a Telegram button (+966537159713).
- `apps-script.gs`: free backend. It saves each request to a Google Sheet and emails the owner. Paste the web-app URL into `ENDPOINT` in `index.html`.
- `logo.svg` / `logo-512.png`: the logo (512 px PNG for the TikTok profile picture). `og.png`: the link-preview image.
